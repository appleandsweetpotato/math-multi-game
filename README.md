# 🐞 乘法小农场 - 拖拽方块学面积

适合三年级小朋友的乘法可视化小游戏，通过拖拽方块搭建长方形，直观理解乘法与面积的关系。

## 🎮 游戏玩法

1. **题目区**：上方显示一道乘法算式，例如 `3 × 4 = ?`
2. **拖拽方块**：左侧有大量苹果方块，可以用鼠标或手指拖拽到右侧的“农场网格”中。
3. **搭建长方形**：在 6x6 的网格中，拼出一个**完整的长方形**（没有缺口）。
4. **自动批改**：
   - 当你拼好长方形后，游戏会自动计算当前长方形的面积（方块总数）。
   - 如果面积与题目答案一致，会显示“正确”并表扬小朋友。
   - 如果面积不对或形状不是长方形，会给出提示。
5. **手动检查**：也可以在输入框中填写答案，点击“✅ 检查”按钮批改。
6. **新题目**：点击“✨ 新题目”可随机生成 1~6 范围内的乘法题。
7. **清空农场**：点击“🧹 清空农场”可重新开始搭建。

## 📱 手机适配

- 完全响应式设计，支持手机触屏拖拽。
- 在手机上，用手指按住方块，拖到目标格子松开即可放置。
- 也可以直接点击空白格子快速放置方块（方便小屏幕操作）。

## 🧠 学习目标

- 理解乘法与面积的关系（长 × 宽 = 面积）。
- 练习 1~6 的乘法口诀。
- 锻炼空间想象和图形构建能力。
